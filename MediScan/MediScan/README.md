# MediScan (React Project Structure)
This folder contains the same MediScan SPA refactored into a standard **Vite + React Router** project structure.
## Run locally
```bash
cd react-project
npm install
npm run dev
```
Then open the URL printed in the terminal.
## Notes
- Tailwind is loaded via CDN in `index.html` for simplicity.
- Data is mocked in `src/data/mockData.js`.
- Auth, membership, profile edit + picture, critical doctor recommendations, booking, doctor appointments list, and admin subscription table are included.
